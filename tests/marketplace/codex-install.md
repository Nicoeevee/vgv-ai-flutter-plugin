# Codex Marketplace Smoke Test

Goal: verify OpenAI Codex can discover and load the plugin.

## Steps

1. Register the marketplace.
2. Install `vgv-ai-flutter-plugin`.
3. Verify `CODEX.md` instructions are loaded.
4. Verify shared skills and agents are available.

Expected result:

- Codex metadata loads successfully.
- Shared Flutter/Dart skills are discoverable.
- Agent workflows remain compatible.
